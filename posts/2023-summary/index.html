2023 年即将结束，回顾这一年的成长与收获。

技术成长

今年学习了很多新技术：

  • 深入学习了 Vue 3 和 Composition API
  • 尝试了 Rust 语言
  • 搭建了自己的博客系统
  • 参与了多个开源项目

阅读

今年读了 25 本书，包括：

  • 《代码大全》
  • 《人月神话》
  • 《深入理解计算机系统》
  • 《黑客与画家》

健康

  • 坚持跑步，全年累计 500 公里
  • 早睡早起，改善作息
  • 学会了做几道拿手菜

2024 年计划

  1. 深入学习系统设计
  2. 贡献更多开源项目
  3. 保持运动习惯
  4. 多陪伴家人

新的一年，继续加油！🎉
